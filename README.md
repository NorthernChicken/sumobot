# Sumobot

Sumobot code for engineering project. Modified from test code written by [Raptorly1](https://github.com/Raptorly1).

Requires Arduino IDE. Wired using an H-Bridge for controlling the motors and providing the motor's power, Arduino (Uno R2 worked best) powered by a second battery. A breadboard was used to wire 5V and ground, but may be unnecessary. Original design included a servo and an Arduino sensor (using NewPing) but it was removed.

Our sequence logic won.
